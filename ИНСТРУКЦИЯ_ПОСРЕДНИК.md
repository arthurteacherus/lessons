# Посредник на Cloudflare (нужен, чтобы планшет мог скачивать файл проекта с Яндекс.Диска)

Яндекс не разрешает браузеру забирать содержимое файла напрямую. Посредник — крошечная программа в интернете: берёт ссылку Яндекса, скачивает/загружает файл сама и отдаёт результат планшету. Ничего не хранит и не видит токен Яндекса (ссылки уже подписаны Яндексом). Работает только для страницы `arthurteacherus.github.io` и только с серверами скачивания/загрузки Яндекс.Диска (код — `cloudflare-worker.js`).

**Честно о приватности:** файл проекта (в нём фамилии учеников и оценки) проходит через серверы Cloudflare по зашифрованному соединению, не сохраняясь. Если это неприемлемо — этот шаг пропускайте, а файл между устройствами переносите вручную.

## Шаги
1. Откройте dash.cloudflare.com/sign-up, зарегистрируйтесь (почта + пароль), подтвердите почту. Карта не нужна.
2. В левом меню откройте **Workers & Pages** (в новом интерфейсе может называться «Compute» → «Workers & Pages») → **Create** → **Create Worker** (шаблон «Hello World») → имя `lessons-proxy` → **Deploy**.
3. Нажмите **Edit code**. В редакторе выделите весь текст (Ctrl+A), удалите и вставьте всё содержимое файла `tablet\cloudflare-worker.js`. Нажмите **Deploy**.
4. Скопируйте адрес воркера (вида `https://lessons-proxy.ВАШЕ-ИМЯ.workers.dev`).
5. На планшете: ☁ → внизу раздел «Посредник для скачивания» → вставьте адрес → **Сохранить** → **Синхронизировать сейчас**.

Прежде обновите планшетную версию на GitHub (загрузить содержимое `tablet\dist`), иначе поля для адреса не будет.
