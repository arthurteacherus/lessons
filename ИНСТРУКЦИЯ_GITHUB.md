# Как выложить версию для планшета на GitHub Pages

Готовые файлы лежат в папке `tablet\dist` (рядом с этой инструкцией). Их содержимое нужно один раз загрузить на GitHub — получится ссылка, по которой планшет откроет программу.

## 1. Аккаунт
1. Откройте github.com → **Sign up**. Введите почту, придумайте пароль и имя пользователя (оно попадёт в ссылку, например `ivanova-uroki`). Подтвердите почту.

## 2. Репозиторий (папка для файлов)
1. Справа вверху нажмите **+** → **New repository**.
2. **Repository name:** `lessons` (латиницей).
3. Выберите **Public** (для бесплатных Pages это обязательно; ваших данных там нет — только код программы).
4. Поставьте галочку **Add a README file**.
5. Нажмите **Create repository**.

## 3. Загрузка файлов
1. В репозитории нажмите **Add file → Upload files**.
2. В проводнике Windows откройте `...\Конструктор уроков\tablet\dist`, нажмите Ctrl+A (выделить всё: файлы и папку `vendor`) и перетащите в окно браузера.
3. Дождитесь, пока все файлы (около 24) появятся в списке, и нажмите зелёную **Commit changes**.

## 4. Включить Pages
1. Вкладка **Settings** репозитория → слева **Pages**.
2. **Source:** *Deploy from a branch*. **Branch:** `main`, папка `/ (root)` → **Save**.
3. Подождите 1–3 минуты и обновите страницу: вверху появится «Your site is live at https://ВАШ-ЛОГИН.github.io/lessons/».

## 5. Дальше
1. Пришлите ссылку — я скажу, какой адрес добавить в настройки приложения на oauth.yandex.ru (Redirect URI).
2. На планшете откройте ссылку в Chrome → меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).

## Обновление версии
Когда я вношу изменения, я пересобираю `tablet\dist`. Чтобы обновить планшет: репозиторий → **Add file → Upload files**, перетащите всё содержимое `dist` ещё раз (файлы с теми же именами заменятся) → **Commit changes**. На планшете новая версия подтянется при втором открытии программы.
